# Архитектурное решение по логированию

![](/Схемы/jewerly_c4_model_logs.png)

## Мотивация

Внедрение логирования позволит детализировать информацию о всех произведенных операциях в системе. 
Эта информация может потребоваться для восстановления картины событий при решении проблем с системе или для быстрого реагирования на инциденты безопасности с случае атаки.

Можно выделить следующие уровни логирования:

- ERROR: Ошибки, которые требуют немедленного вмешательства.
- WARN: Ошибки, которые требуют внимания. Например ошибки авторизации пользователей
- DEBUG: Подробная информация для разработки, включается при необходимости.   
  Например информация о переданных данных в сервис внешней системы для решения спорных ситуаций.
- INFO: Регистрация всех операций с системе с целью дальнейшего разбора при необходимости.

## Предлагаемое решение

Для реализации системы логирования будет использован ELK Stack:
- Elasticsearch будет использоваться для хранения логов
- Logstash — для их обработки и передачи
- Kibana — для визуализации и анализа.

Компоненты для внедрения:

- Библиотека логирования с каждый сервис;
- Поставка логов напрямую в RabbitMQ из приложений или по средствам агента Filebeat
- Очередь сообщений для поставки логов в RabbitMQ.
- Настройка инструментов Logstash, Elasticsearch, Kibana

Политика безопасности:

- Ограничение доступа к логам по ролям сотрудников;
- Скрытие/удаление чувствительной информации из логов. (Например номера карт, пароли и прочее)

Политика хранения:

- Хранение логов в отдельном индексе для каждой подсистемы;
- Срок хранения логов настраиваемый (По умолчанию 7 дней для ошибок, 90 дней и более для логов аудита);
- Архивирование/партиционирование логов для быстрого обращения к более свежим логам

## Анализ логов

- Настройка уведомлений о критических ошибках и аномалиях;
- Выявление подозрительной активности, например, резкое увеличение числа заказов или большое количество ошибок авторизации
- Возможно последующий анализ логов в системах безопасности (IDS (`Intrusion Detection System`), DLP (`Data Loss Prevention`))
